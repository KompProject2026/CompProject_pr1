# Пружне відбиття кулі від стінок

Навчальний проєкт з інформатики (варіант 12). Програма на C# (Windows Forms) моделює рух кулі в прямокутній коробці з абсолютно пружним відбиттям від стінок.

## Можливості

- Моделювання руху кулі з відбиттям від чотирьох стінок
- Параметри: розміри коробки, початкове положення, радіус кулі, швидкість і кут запуску
- Модель оновлюється одразу при зміні параметрів, без окремої кнопки
- Керування анімацією: старт/пауза, покроковий режим, повернення на початок, регулювання швидкості відтворення
- Налаштування вигляду: слід кулі, вектор швидкості, сітка, точки ударів з номерами, інфопанель
- Порівняння кількох запусків з різними параметрами на одному полотні
- Експорт зображення полотна у PNG

## Фізична модель

Відбиття пружне: при ударі змінює знак лише та складова швидкості, що перпендикулярна до стінки. Модуль швидкості не змінюється, а кут падіння дорівнює куту відбиття. Куля має радіус `r`, тому її центр рухається в зменшеній коробці.

## Запуск

1. Відкрийте файл проєкту (`.sln`) у Visual Studio.
2. Виконайте **Build → Rebuild Solution**.
3. Натисніть `F5`.

Потрібна Windows і Visual Studio з компонентом розробки для Windows Forms (.NET).

## Як користуватися

1. На вкладці **«Модель»** задайте параметри. Умова коректності: `2r < min(W, H)`.
2. Натисніть **«Старт»**, щоб запустити рух, **«Крок»** для покрокового перегляду, **«На початок»** щоб повернути кулю в стартову точку.
3. На вкладці **«Вигляд»** вмикайте й вимикайте елементи малюнка.
4. На вкладці **«Порівняння»** натисніть «Додати поточний запуск», змініть параметри й додайте ще один. Криві показуються пунктиром різних кольорів з легендою.
5. Кнопка **«Зберегти PNG»** зберігає поточне зображення полотна у файл.

## Структура проєкту

- `Form1.cs` — логіка моделі, малювання й обробники подій
- `Form1.Designer.cs` — розмітка форми (генерується Visual Studio)
- `Canvas.cs` — полотно з подвійною буферизацією (щоб не мерехтіло)
